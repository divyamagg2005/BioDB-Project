# Phase 6: Baseline Model

## Setup

Run with `python -m biodb.phase6_baseline`. The shared training code is in `src/biodb/modeling.py`.

- **Features (19):**
  - the `conventional` group: CADD, REVEL, AlphaMissense, SIFT, PolyPhen-2, GERP, gnomAD AF, gnomAD-absent flag;
  - the `substitution` group: BLOSUM62, hydropathy, volume, charge, Pro/Gly/Cys flags.
  
  No AlphaFold structure features and no ΔΔG.
- **Validation:** 5-fold `StratifiedGroupKFold` grouped by gene, seed 42.
  - Each fold holds 20 genes and 1,000 variants (500 per class).
  - No gene appears in more than one fold; an assertion checks this for every split.
  - Fold assignments are saved in `results/metrics/folds.csv` and reused unchanged by every later experiment.
- **Models:** fixed hyperparameters, no tuning (`modeling.MODEL_PARAMS`). Imputation and scaling are fitted inside each training fold; XGBoost uses missing values natively.
  - logistic regression: median imputation + scaling;
  - random forest: 500 trees, median imputation;
  - XGBoost: 400 trees, depth 4.
- **Threshold:** 0.5 for the threshold-based metrics.

## Results (mean ± SD over 5 gene-grouped folds)

| Model | ROC-AUC | PR-AUC | Accuracy | Precision | Recall | F1 | MCC | Brier |
|---|---|---|---|---|---|---|---|---|
| Logistic regression | 0.974 ± 0.005 | 0.973 | 0.913 | 0.909 | 0.918 | 0.914 | 0.826 | 0.062 |
| **Random forest** | **0.978 ± 0.005** | 0.974 | 0.925 | 0.928 | 0.922 | 0.925 | 0.851 | 0.058 |
| XGBoost | 0.974 ± 0.006 | 0.972 | 0.919 | 0.915 | 0.925 | 0.920 | 0.839 | 0.063 |

Pooled out-of-fold confusion matrix for random forest: 2,320 TN, 180 FP, 194 FN, 2,306 TP.

Most important features:
- random forest: AlphaMissense, REVEL, gnomAD-absent;
- XGBoost: AlphaMissense, gnomAD AF, REVEL;
- logistic regression (largest absolute coefficients): gnomAD-absent, gnomAD AF, REVEL, AlphaMissense.

## Interpretation

The baseline is already near the ceiling even though whole genes are held out. Two reasons:
- The VEP predictors are themselves trained on, or calibrated against, clinical variant data.
- ClinVar submitters use these predictors (ACMG PP3/BP4) and population frequency (BA1/BS1) as classification evidence.

Part of this performance is therefore circular. Any gain from ΔΔG on top of this baseline will be small by construction. Phase 7 therefore also evaluates feature sets without the predictors and gnomAD.
